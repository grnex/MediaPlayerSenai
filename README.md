Media Player SENAI--

Projeto desenvolvido como atividade do curso de Desenvolvimento de Sistemas do SENAI.

Sobre o projeto//

O MediaPlayer será uma aplicação web voltada para reprodução e descoberta de músicas.

O sistema será integrado à API do Spotify, permitindo utilizar informações de músicas, artistas, álbuns e playlists dentro da aplicação.


Objetivo//

Desenvolver um Media Player Web capaz de oferecer uma experiência simples para o usuário explorar e reproduzir conteúdos musicais utilizando recursos disponibilizados pelo Spotify. Desenvolver um sistema
de geração de Playlist baseado no gosto do usuário, por meio de um algoritmo próprio.

Funcionalidades planejadas
- Visualização de músicas
- Consulta de artistas
- Consulta de álbuns
- Pesquisa de músicas e artistas
- Controles de reprodução
- Criação e gerenciamento de playlists
- Integração com a API do Spotify
- Criação de Playlist diferenciada

Tecnologias//

O projeto ainda está em desenvolvimento. As tecnologias utilizadas serão adicionadas conforme a implementação avançar.

Principais recursos previstos:

Desenvolvimento Web
API REST
Spotify Web API
